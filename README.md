# Entrada do Marte Alma no domínio raiz

O projeto principal continua em https://github.com/canneli/martealma.

Esta entrada disponibiliza a página inicial em https://canneli.github.io e o ads.txt na raiz, como exigido pelo AdSense. Não cria um segundo banco nem contas separadas: scripts, estilos e conteúdo continuam vindo de /martealma/.

O index.html é o arquivo do projeto principal com uma base HTTPS apontando para /martealma/. Ao alterar o código de inicialização ou o cabeçalho do projeto principal, sincronize também esta cópia. Mudanças em public-views.js, editorial.css e conteúdos no Firebase são compartilhadas automaticamente.
